# 🎨 UI/UX Refinement: The Cognitive Lab

The frontend of **eduRAG** must be upgraded to visualize the newfound intelligence of the system.

## ✨ New Features

### 1. The Knowledge Navigator
- A 2D/3D force-directed graph view of the document's concepts.
- Color-coded nodes (Green = Mastered, Red = Hard for User, Blue = Unvisited).
- Clickable nodes to open associated study materials.

### 2. Multi-File Reasoning Dashboard
- A "Workspace View" that shows how different files in a folder relate to each other.
- "The Bridge": A split-view showing how Concept A in File 1 connects to Concept B in File 2.

### 3. Integrated Study Lab
- Redesign the current Studymines dashboard to include "Graph Context" sidebar.
- While reading a summary, show a list of "Prerequisites" and "Next Steps" generated by the AI.

## 🛠️ Stack Update

- **Visualization**: `react-force-graph` or `vis.js` for the Knowledge Graph.
- **State Management**: React Context or Redux to keep the Graph and Chat in sync.
- **Interactions**: Drag-and-drop file organization with automatic graph re-clustering.
