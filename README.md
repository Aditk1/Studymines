# 🧬 eduRAG: Cognitive Learning System

**eduRAG** is the evolution of **Studymines** and **RLM-GraphRAG**, combining adaptive study materials with a world-class Knowledge Graph for deep, cross-document reasoning.

## 🗂️ Project Structure

- **`/edu`**: The Studymines codebase (Backend, Frontend).
- **`/Final-year-project`**: The RLM-GraphRAG codebase (Graph Pipeline).
- **`/implementation_plan`**: Detailed specs for the integration.

## 🛠️ Integrated Functionalities

- **Hybrid Search**: Semantic vector retrieval + Multi-hop graph traversal.
- **Automated Summarization**: Graph-aware summaries that highlight key entities.
- **Adaptive Tutoring**: AI tutors that identify knowledge gaps using the graph.
- **Graph Visualization**: Interactive 3D maps of your learning journey.
